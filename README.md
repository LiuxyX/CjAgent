# 🌊 水域监管智能体  - 使用指南
本项目是一个基于大语言模型与计算机视觉的端云协同智能体。

## 1. ⚙️ 后端服务启动
进入 `WATER_BACKEND` 文件夹，根据 `README.md` 启动后端服务。

## 2. 📱 前端配置与启动
 在启动鸿蒙端 App 之前，需确保端云网络互通：
找到全局配置文件`Config.cj`，将其中的`HOST_IP`值更改为您**本机的 IPv4 地址**，然后编译并运行项目。
### 前端目录结构
```plaintext
combine [Agent0303] (项目根目录)
├── .hvigor/                # 构建工具配置（HarmonyOS 的构建助手）
├── .idea/                  # IDE 配置文件（DevEco Studio 相关）
├── AgentVisionConnector/   # 独立的功能模块/库（视觉连接器）
│   ├── src/
│   │   └── VisionClient.cj # 视觉客户端的核心实现
│   ├── cjpm.lock           # 仓颉包管理锁定文件
│   └── cjpm.toml           # 仓颉包管理配置文件
├── AppScope/               # 应用全局配置（图标、名字等）
└── entry/                  # 【核心】应用主模块
    ├── libs/               # 第三方库依赖
    └── src/
        └── main/           # 源码主目录
            ├── cangjie/    # 仓颉代码逻辑层
            │   ├── agent/  # AI 智能体核心逻辑
            │   │   ├── executor.cj # 执行器（处理 Agent 动作）
            │   │   ├── llm.cj      # 大模型对接逻辑
            │   │   └── tools.cj    # 工具集定义
            │   ├── config/ # 配置文件存放地（如 API 地址、密钥等）
            │   ├── ability_stage.cj # 应用生命周期管理
            │   ├── index.cj         # 登录页/入口页逻辑
            │   ├── main_ability.cj  # UIAbility 主程序入口
            │   └── page_alert.cj    # 异常告警看板页面代码
            ├── resources/  # 资源文件（图片、多语言字符串、JSON 配置）
            └── module.json5 # 模块配置文件（权限声明、页面注册）
```

## 4. 🤖 核心功能
进入主界面后，您可以通过自然语言与水域监管 Agent 进行交互。以下是根据不同业务场景的测试指令：

### ⏪ 场景一：历史巡查与设备状态检索
Agent 支持通过自然语言进行时空检索，精准定位历史违规事件片段，并实时查询前端感知设备的在线健康度。

#### 💬 测试指令示例：
- "调出昨天下午 3 点发现非法垂钓时的那段监控视频。"
- "本周的视频在线率是多少？有没有掉线的摄像头？"

---

### 📊 场景二：智能监管报告生成
Agent 能够根据实时拦截的数据和历史统计库，自动生成包含图表和文字分析的结构化报告。

#### 💬 测试指令示例：
- "生成本周水域监管数据总结报告。"
---
### ⚙️ 后台自动化运行模块

除了上述问答式交互外，本系统还搭载了全天候自动运行的视觉与控制模块，点击主页面"异常事件看板"按钮：

#### 🌫️ 智能去雾算法
当摄像头识别到当前水域能见度低于设定阈值时，自动触发基于物理模型的去雾算法，提升画面清晰度。

#### 🗑️ 河湖库环境问题识别
后台周期性自动检测水面漂浮垃圾、河岸垃圾堆放等环境异常，生成预警并推送给对应巡检员。

#### 🚫 违法行为识别与干预
持续高频检测采砂船、违规下河、违规垂钓、翻越围栏等事件。一旦确认，系统将自动触发端侧警报音频，并记录上报。
