# 🌊 Water-Backend (水域监管智能体 -后端服务)

本项目是“水域监管智能体”的统一后端 API 服务。采用 Python 编写，基于高度模块化的 FastAPI `APIRouter` 架构，为前端（仓颉）提供高效、低延迟的 RESTful 接口与流媒体服务。

## 🧩 核心功能模块

本项目将四大核心微服务完美整合于单一的 8000 端口下：

* **🔐 权限认证 (Auth)**：提供多角色巡检员的模拟登录与鉴权校验。
* **📊 设备监控 (Device)**：实时返回各个水域分局（如跃进河、长明水库）的前端监控设备在线率与健康状态。
* **⏪ 历史记录 (History)**：基于自然语言筛选的历史视频检索，支持按时间、地点、事件类型智能调取录像。
* **👁️ 视觉感知 (Vision)**：集成 YOLOv8 与 OpenCV，提供实时的水面垃圾检测、违规行为拦截以及自动拉普拉斯测雾与去雾算法。
* **🤡 模拟测试 (Mock)**：独立于主服务之外的轻量级测试引擎，专供前端大屏看板进行异常警报的随机触发与 UI 渲染测试

## 📁 目录结构说明

```plaintext
water-backend/
├── main.py              # 全局总启动入口（路由挂载与应用初始化，端口 8000）
├── mock_server.py       # 前端大屏 UI 测试专用的模拟服务器（端口 8002）
├── routers/             # 业务路由模块
│   ├── auth.py          # 登录校验模块
│   ├── device.py        # 设备状态模块
│   ├── history.py       # 历史视频检索模块
│   └── vision.py        # 视觉检测与流媒体模块
├── static/              # 历史录像与测试视频静态资源库（.mp4）
└── vision_assets/       # 视觉模型资产库（存放 yolov8n.pt 与测试视频流）

```
## 🛠️ 快速启动指南

### 1. 安装核心依赖
建议在 Python 虚拟环境中运行。在当前目录打开终端，执行以下命令安装核心算法与 Web 框架依赖：
```bash
pip install fastapi uvicorn opencv-python ultralytics
```

### 2. 启动服务
配置完成后，请在项目根目录打开两个终端，分别拉起真实的 AI 服务和测试服务：

#### 终端1
```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```
#### 终端2
```bash
python mock_server.py
```
